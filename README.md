# Пятёрка — автономный тренажёр по математике (5 класс)

Статический PWA: `index.html` + `manifest.webmanifest` + `sw.js` + `icons/`. Никаких зависимостей и сборки.

## Как выложить (любой из вариантов, 5 минут)

**GitHub Pages**: создай репозиторий, положи содержимое этой папки в корень, Settings → Pages → Branch `main` / root. Адрес: `https://<user>.github.io/<repo>/`.

**Netlify / Cloudflare Pages / Vercel**: перетащи папку в интерфейс — получишь адрес вида `https://xxx.netlify.app`.

**Свой сервер**: любой nginx/apache, обязательно HTTPS (иначе не установится как приложение и не заработает офлайн).

## Как поставить на планшет/телефон

- Android (Chrome): открыть адрес → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- iPad / iPhone (Safari): «Поделиться» → «На экран Домой».

После первого открытия приложение работает без интернета (кроме видео на YouTube).

## Личный кабинет (общий прогресс на всех устройствах)

Кабинет работает на Supabase (бесплатный тариф): аккаунт родителя по e-mail, профили детей, прогресс и история уроков.

1. https://supabase.com → New project.
2. SQL Editor → вставить и выполнить `supabase/schema.sql`.
3. Authentication → Providers → Email → выключить «Confirm email» (иначе регистрация потребует подтверждения письмом).
4. Settings → API → скопировать Project URL и anon public key в `index.html`:
   `window.PYATERKA_SUPABASE={url:'https://xxxx.supabase.co',anon:'eyJ...'};`
5. (Рекомендуется) Authentication → URL Configuration → Site URL = адрес приложения.

anon-ключ публичный по дизайну: доступ к данным ограничен политиками RLS из `schema.sql` (каждая семья видит только своё).

Как пользуется семья: родитель один раз входит на каждом устройстве ребёнка и выбирает профиль — устройство запоминает выбор. Прогресс синхронизируется автоматически (при каждом сохранении и каждые 30 секунд), история уроков — в разделе «Для родителей». Без интернета приложение работает дальше и досылает изменения при подключении.

Если `PYATERKA_SUPABASE` пустой, приложение работает без аккаунтов: прогресс на устройстве + «код переноса».

## Обновления

Файлы можно менять напрямую: видео — массив `TOPICS` в `index.html` (поле `videos`: подпись и id YouTube), задания — объект `GEN`. После изменения `sw.js` подними версию `CACHE`.
