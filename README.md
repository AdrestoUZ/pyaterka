# Пятёрка — автономный тренажёр по математике (5 класс)

Статический PWA: `index.html` + `manifest.webmanifest` + `sw.js` + `icons/`. Никаких зависимостей и сборки.

## Как выложить (любой из вариантов, 5 минут)

**GitHub Pages**: создай репозиторий, положи содержимое этой папки в корень, Settings → Pages → Branch `main` / root. Адрес: `https://<user>.github.io/<repo>/`.

**Netlify / Cloudflare Pages / Vercel**: перетащи папку в интерфейс — получишь адрес вида `https://xxx.netlify.app`.

**Свой сервер**: любой nginx/apache, обязательно HTTPS (иначе не установится как приложение и не заработает офлайн).

## Как поставить на планшет/телефон

- Android (Chrome): открыть адрес → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- iPad / iPhone (Safari): «Поделиться» → «На экран Домой».

После первого открытия приложение работает без интернета (кроме видео на YouTube).

## Общий прогресс между устройствами (необязательно)

Без сервера прогресс живёт на устройстве, а переносится «кодом переноса» в разделе «Для родителей».

Чтобы прогресс был общим автоматически, подними крошечный сервер хранения (Cloudflare Worker + KV, бесплатный тариф):

```bash
cd sync-worker
npm i -g wrangler && wrangler login
wrangler kv namespace create PROGRESS   # вставь полученный id в wrangler.toml
wrangler deploy                          # получишь https://pyaterka-sync.<acc>.workers.dev
```

Затем в `index.html` впиши адрес: `window.PYATERKA_SYNC_URL='https://pyaterka-sync.<acc>.workers.dev';`
В приложении появится раздел «Семейный код»: один код вводится на всех устройствах ребёнка.

## Обновления

Файлы можно менять напрямую: видео — массив `TOPICS` в `index.html` (поле `videos`: подпись и id YouTube), задания — объект `GEN`. После изменения `sw.js` подними версию `CACHE`.
